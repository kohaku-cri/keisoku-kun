# 計測くん（keisoku-kun）

MinecraftBEアドオン

お手軽に使えるワールド内タイマー

制作時間の計測やマップのクリア時間計測などに

## 競合について
可能な限り他のシステムと競合しないように設計しているため、アドオンの優先順位は一番下にしても構いません。

もしも競合したならあなたは豪運の持ち主です！

## コマンド構文

共通のプリフィックス：`keisoku555`

Admin = OP権限を持つプレイヤー

### コマンド一覧

#### `/start`

- **説明**：計測を開始、または再開する
- **権限**：Admin

#### `/stop`

- **説明**：計測を停止する
- **権限**：Admin

#### `/reset`

- **説明**：現在の経過時間をリセット（0に戻す）
- **権限**：Admin

#### `/show`

- **説明**：現在の計測時間をGUIで表示
- **権限**：Any
- **備考**：プレイヤーのみが実行可能

#### `/setting`

- **説明**：アドオンの設定を開く
- **権限**：Admin
- **設定項目**：
  - 再読み込み時にカウントの自動再開をチャットに通知するか（既定：True）

## 仕様

- １秒単位で測定され、スコアボードに記録されます
- 厳密な正確性は考慮していません。あくまで目安として（普通に使う分には問題ないはず...）
