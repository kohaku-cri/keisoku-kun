# 計測くん（keisoku-kun）

MinecraftBEアドオン

シンプルなワールド内ストップウォッチ

制作時間やマップのクリア時間の計測とかに

## 競合について

可能な限り他のシステムと競合しないように設計しているため、アドオンの優先順位は一番下にして構いません。

## コマンド構文

共通のプリフィックス：`keisoku555`

Admin = OP権限を持つプレイヤー

### コマンド一覧

#### `/count`

- **説明**：操作画面を開く
- **権限**：Admin
- **選択項目**
  - 計測スタート・ストップ・再開
  - 計測をリセット
  - 現在タイムを確認
  - 設定
    - **設定項目**：
    - 再読み込み時にカウントの自動再開をチャットに通知するか（既定：True）
    - カウントリセットの確認を厳格にするか（既定：True）

#### `/show`

- **説明**：現在の計測時間をGUIで表示
- **権限**：Any
- **備考**：menuの「現在タイムを確認」と同じ


## 仕様

- １秒単位で測定され、スコアボードに記録されます（つまり、約21億秒が上限です）
- 厳密な正確性は考慮していません。あくまで目安として（普通に使う分には問題ないはず...）

## 注意

すべてのコマンドはプレイヤーが実行すること前提で設計しています。（実行者チェックなし）

自動再開のチャット通知は、パックのリロードから長くても数十秒以内にプレイヤーが存在すること前提で設計しているため、サーバーなどプレイヤーが存在せずにスクリプトが実行される可能性がある場合、プレイヤーが現れるまで10ティック毎にチェック処理が実行されます。

簡易的な時間計測を目的に制作したため、処理の最適化や例外処理が不十分です。
